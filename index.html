Secure RAG chatbot with role-based access

A document assistant that answers with citations and only retrieves what each user's role is allowed to see.

11permission test cases

  • Built on LangChain, Groq LLMs, Qdrant and Sentence-Transformers, with Docling ingestion, header-aware chunking and source-cited answers in a Streamlit UI.

  • Automated Ragas evaluation in GitHub Actions, with LangSmith tracing, per-request cost tracking and Docker deployment.

Hybrid NLP log classification

A three-tier pipeline that sends each log to regex, an ML model or an LLM, balancing cost against accuracy.

99%accuracy on held-out data
0.98macro F1 score
2,400+logs clustered into rules
  • Routes logs by source across three tiers: regex rules, an embedding-based classifier and an LLM fallback.
  • Trained Logistic Regression on all-MiniLM-L6-v2 embeddings, with confidence thresholding for uncertain predictions.
  • Ran DBSCAN on sentence embeddings to discover recurring patterns and turn them into regex rules, cutting load on the ML and LLM layers.
  • Used a Groq-hosted LLM with structured prompting for low-data sources, served as a Dockerized FastAPI service.
